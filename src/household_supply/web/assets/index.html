Общий список потребностей — блюда и весовые товары

Показывает все ингредиенты, включая товары без подтверждённых правил продажи. Неизвестный остаток не считается нулём, а просмотр не сохраняет закупку.

Если среди недостающих товаров есть весовые позиции без подтверждённого шага продажи, полноценный план заблокирован. Для фасованных товаров используйте обычный расчёт ниже.

Единая закупка: рецепты, упаковки и вес — закрытый пилот

Создание плана доступно только при отдельно проверенных правилах продажи весовых товаров. Публичная цена Globus за кг сама по себе недостаточна. Это список будущей покупки, не заказ у магазина.

Что требуется купить?

Изменение бюджета или ингредиентов после расчёта отменяет подтверждение. Записать покупку в домашние запасы можно только после отдельной сверки фактического чека.

Что приготовить из того, что есть дома?

Рецепты опираются на последние записанные остатки. Если продукт давно не проверяли, уточните количество перед готовкой.

Подбираем до шести блюд за запрос, чтобы не опрашивать магазин без ограничений. Ориентировочная стоимость относится к целым упаковкам; неизвестный остаток не считаем нулём. Список покупок сохраняется только после отдельной проверки выбранного рецепта.

Товары на вес — справочный расчёт

Цена за килограмм не означает фиксированную упаковку. Расчёт не создаёт список покупок и не учитывает неизвестные остатки.

Без подтверждённых правил минимального веса и шага продажи позицию нельзя сохранить как закупку.

Моя обычная закупка

Выберите привычные товары. Если истории расхода пока нет, можно явно указать резервное количество на эту закупку.

«Повторить» использует только бюджет и срок последнего подтверждённого привычного плана. Остатки, потребности и цены рассчитываются заново. Предпросмотр не создаёт покупки.
